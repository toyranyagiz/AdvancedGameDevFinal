# Key Escape

**Key Escape** is a first-person horror survival game developed with Unreal Engine 5.

The game takes place in an abandoned hospital where the player must survive against zombies, collect useful items, find keys, open locked doors, and escape from the building.

## Features

- First-person player controller
- Main menu, tutorial level, pause menu, win and lose screens
- Interaction system
- Inventory system with item slots
- Flashlight and battery system
- Health and damage system
- Pistol, ammo, reload and shooting mechanics
- Molotov and fire damage area
- Zombie AI with patrol, chase, attack and death animations
- Key and locked door system
- Readable notes
- Spike trap
- Sound effects and background music

## Controls

| Action | Key |
|---|---|
| Move | WASD |
| Look | Mouse |
| Sprint | Left Shift |
| Interact | E |
| Use Item / Shoot | Left Mouse Button |
| Reload | R |
| Flashlight | F |
| Switch Item | 1 / 2 / 3 / 4 |
| Drop Item | G |
| Pause | ESC |

## Goal

The player's goal is to explore the abandoned hospital, survive zombie attacks, collect the required key, and reach the exit.

## Engine

Developed with **Unreal Engine 5**.
